## Part 1: Foundational Mathematics

### 1.1 Braid Group B_n

The Artin braid group B_n is generated by n-1 generators with specific relations:

**Generators:**
```
σ_i : cross strand i over strand i+1 (for i = 1, ..., n-1)
σ_i^{-1} : uncross (cross strand i+1 over strand i)
```

**Relations:**
```
Type I (Inverse):      σ_i · σ_i^{-1} = ε (identity)
Type II (Braid):       σ_i · σ_{i+1} · σ_i = σ_{i+1} · σ_i · σ_{i+1}
Type III (Commute):    σ_i · σ_j = σ_j · σ_i  for |i - j| ≥ 2 (far-commutativity)
```

### 1.2 Invariant Tuple I(β)

Every braid word β has an associated invariant tuple that characterizes its topological properties:

```
I(β) = (A(β), w(β), ℓ(β), M(β), P(β))
```

Where:
- **A(β)** = Active Strands: Set of strand indices that are involved in crossings
- **w(β)** = Writhe: Sum of exponents of all generators
  - w(β) = Σ sign(σ_i) for each generator
  - Positive crossings (+1), negative (-1)
- **ℓ(β)** = Word Length: Number of generators in the braid
- **M(β)** = Generator Multiset: Count of each generator type
  - M(β) = {σ_1: count_1, σ_2: count_2, ...}
- **P(β)** = Pattern Class: Sequence of absolute generator indices
  - P(β) = (|σ_i₁|, |σ_i₂|, ..., |σ_iₙ|)

**Example:**
```
β = σ₁ · σ₂ · σ₁

I(β) = (
  A(β) = {1, 2, 3},           // affects strands 1, 2, 3
  w(β) = 3,                    // three positive crossings
  ℓ(β) = 3,                    // three generators
  M(β) = {1: 2, 2: 1},         // σ₁ twice, σ₂ once
  P(β) = (1, 2, 1)            // pattern sequence
)
```

**Implementation:**
```typescript
invariants(): BraidInvariant {

  }
  
  return { activeStrands, writhe, wordLength, generatorMultiset, patternClass };
}
```
